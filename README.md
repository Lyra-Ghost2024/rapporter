# Rapporter

Dette repoet brukes til å samle rapporter, utkast og relevant dokumentasjon fra prosjektet.

## Struktur

Lag en egen mappe for arbeidet ditt og legg filene dine der.

## Første gang

```bash
git clone https://github.com/Lyra-Ghost2024/rapporter.git
cd rapporter
mkdir min-rapport
```

Legg filene dine i mappen, og last dem opp:

```bash
git add .
git commit -m "Første utkast av rapport x"
git push
```

## Senere opplastinger

```bash
git pull
git add .
git commit -m "Oppdaterte rapport x"
git push
```

## Viktig

Dette er et offentlig repo. Ikke del noe som ikke kan offentliggjøres.
